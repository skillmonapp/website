# Skillmon Website

A futuristic splash page for Skillmon, built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Start the development server:**
   ```bash
   pnpm dev
   ```

3. **Build for production:**
   ```bash
   pnpm build
   ```

## 🛠 Tech Stack

- **Framework:** Astro 5
- **Styling:** Tailwind CSS 4
- **Fonts:** Exo 2 via Fontsource
- **Icons:** Custom SVG logo

## 🎨 Theme

- **Background:** `#0a0a0a` (Dark)
- **Primary Color:** `#004a52` (Skillmon Teal)
- **Typography:** Exo 2
